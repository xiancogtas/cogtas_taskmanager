## Project Description

Orbit Task Manager is a personal task tracking app built with Laravel. It lets users add, view, edit, and delete tasks, then track each one as pending or completed from a red galaxy-themed dashboard.

## Features

- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Status (Pending or Completed)
